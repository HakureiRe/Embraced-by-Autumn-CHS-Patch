【适用游戏】
  - Embraced By Autumn (Steam 版 / 原版 1.0)
  - Ren'Py 引擎版本：7.4.4.1439
  - 支持 Windows / macOS / Linux 各版本

【手动安装步骤】
  1. 找到游戏的根目录
  2. 把本补丁 game 文件夹复制进根目录并选择覆盖
  3. 删除游戏 game/cache/ 下的 bytecode.rpyb、pyanalysis.rpyb、screens.rpyb
     （防止旧缓存导致旧文本报错）
  4. 首次启动后游戏即为中文版

【翻译内容】
  - 全部剧情对话与旁白独白（序章 + 克洛蒂娜 / 露丝 / 米拉贝尔 / 塞琳 四条线）
  - 角色名、主菜单与游戏菜单、快捷菜单、存档界面、按键帮助、音乐盒曲名
  - 章节日期标题与存档名、通关制作名单、游戏标题「秋之拥抱」
  - Ren'Py 引擎公共界面文本（确认框、无障碍设置等）
